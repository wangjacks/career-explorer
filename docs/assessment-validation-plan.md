## 3. 决策结论（逐条回答 issue）

### 3.1 样本来源与规模

- **来源**：合作班级**整班施测**（自然班，不按兴趣挑选、不公开个人分数）。整班施测避免自选偏差；跨班/跨年级各取样可检验稳定性。
- **规模**：
  - 内部一致性与常模：**有效样本 ≥ 60**（Cronbach's α 的估计在 n<60 时置信区间偏宽，60 是可接受下限；**推荐 ≥ 100**，跨班复验更好）；
  - 重测：**≥ 30 对**（间隔 7–14 天）；
  - 校标效度：**≥ 40 人**双答（中文改编版 + 英文原版或已发表的中文版本）。
- **剔除规则（事先固定、写进报告）**：草稿（`in_progress`）不计；完成记录中缺失任一题的不计（当前系统不会产生）；连续同选项比例 ≥ 90% 的记录标记为「疑似无效作答」，由指导教师判断是否剔除；同一学生多轮只取最新一轮进外部效度分析，重测分析另行配对。
- **伦理**：施测前告知用途与匿名处理，允许退出；报告只出聚合值，不出现姓名/学号/单条作答。

### 3.2 验证指标与最低要求

| 指标 | 方法 | 判定线 | 数据要求 |
|---|---|---|---|
| 内部一致性 | 每维 **Cronbach's α**（该维 5 题，反向题先重编码） | **α ≥ 0.7 可接受，≥ 0.8 良好**；任一模低于 0.6 视为不达标 | 每维有效样本 ≥ 60 |
| 题总相关 | **校正题总相关 CITC**（该题与其余题之和的相关） | **≥ 0.3**；低于阈值进「复核清单」，连续两轮不达标 → 改题或删题 | 同上 |
| 重测信度 | 同一学生相邻两次完成（间隔 7–14 天）的六维标准分 **Pearson r** | **r ≥ 0.7** | 配对 ≥ 30 |
| 区分/结构效度（参考） | 六维间相关矩阵；n ≥ 100 时做探索性因子分析（EFA，预期 6 因子） | 维度间大致 0.2–0.6；同维相关应高于跨维；某两维 > 0.85 提示题目重叠 | n ≥ 100（EFA） |
| 校标效度 | 与**英文原版**（或已发表中文版）同维分的相关 | **≥ 0.6**；小样本（< 60）可放宽到 0.5 并在报告注明 | 双答 ≥ 40 |
| 内容效度 | 指导教师 + 英语/心理学科教师逐题审阅（翻译对等、双否、文化适配） | 逐题意见留档，无争议题 | 专家 2–3 人 |

> 30 题总量表的 α 作为参考（≥ 0.8），**不作为判定主依据**：六维是异质构念，总量表 α 高只说明题目互相关联，不说明维度单独可用。

### 3.3 中文常模：要不要换、谁来定、怎么换

- **结论：验证通过前保持线性标准分，不替换常模。** 理由：常模是「解释分数的参照系」，样本不足时百分位会比线性分更误导；当前线性分只用于**相对比较**（同一学生六维高低、三字码排序），不对外宣称「高于全国 X%」。
- **什么时候上常模**：首轮验证通过且样本 ≥ 100（推荐 ≥ 200 且跨年级）后，由**指导教师 + 学科负责人审定**阈值与发布口径；常模表必须标注样本来源、时间、样本量与适用人群。
- **实现预案（另开 Issue，接口不变）**：
  - 分数语义：`scores_json` 已存原始分与线性标准分；常模落地时新增版本化的百分位字段（例如 `percentile`），**旧结果不回算**（快照原则）；
  - 换算来源：`src/lib/assessment-norms.ts` 常量表（或新表 `assessment_norms`，按 `assessment_id + scale_version + dimension` 存 P10…P90），发布时随 `scale_version` 升版；
  - 展示：结果页与职业推荐接口（#226）的「standard」继续保持同一含义，界面新增「百分位」展示与常模说明；接口结构不变；
  - 回滚：常模常量按版本落库/落代码，切回线性换算只需改版本开关。
- **不能做的事**：用未经审定的样本悄悄换分数；把百分位写成「超过全国 X%」；把常模用于心理诊断（免责声明不变）。

## 4. 验证流程 SOP（照做即可）

1. **准备**：确认当前量表版本（`assessments.scale_version`）与题库版本；打印统一指导语（「凭第一感觉选愿不愿意，没有对错」）；完成知情同意。
2. **施测**：学生登录 → 学生面板「职业测评」→ 全部答完并提交（系统自动存草稿、可续答）。**结果只本人可见**，不集体宣读。
3. **重测**：首测后 7–14 天，对参与重测的班级再完整作答一次（系统会生成新版本，历史版本保留）。
4. **取数**：
   - SQLite 部署：`npm run validate:assessment -- --db ./data/career.db --out report.md`
   - MySQL 部署：按附录 A 的 SQL 导出 JSON，再 `npm run validate:assessment -- --export responses.json --out report.md`
5. **出报告**：脚本输出 Markdown（样本、α + CITC、维度相关、重测、百分位候选、判定汇总、局限声明）。报告**只含聚合值**。
6. **复核**：逐条看低 CITC 题与低 α 维度，回看题面（翻译歧义、双重否定、文化不适配、维度归属错）；需要改题时同时升题面版本并记录改动。
7. **判定与留档**：按 §5 出「通过 / 部分通过 / 不通过」，签名归档；通过则开常模实现 Issue，不通过则改题后进入下一轮。
8. **伦理收尾**：原始导出文件脱敏保管、按约定销毁；报告与结论不出现可识别个人的信息。

## 5. 判定规则（通过 / 部分通过 / 不通过）

| 结论 | 条件（同时满足） | 处置 |
|---|---|---|
| **通过** | 全部维度 α ≥ 0.7；CITC 无 < 0.3（或已复核修订并复验）；重测 r ≥ 0.7；有效样本 ≥ 60；题面专家审阅无重大异议 | 可用于正式使用；进入常模 Issue（n ≥ 100 时） |
| **部分通过** | 主要维度达标，但个别维度 α 0.6–0.7 或个别题 CITC < 0.3 | 结果页标注「试用版」；修订题面后下一轮复验；暂不上常模 |
| **不通过** | ≥ 2 维 α < 0.6，或重测 r < 0.5，或有效样本 < 40，或专家审阅存在重大内容问题 | 停止对外使用，回到翻译/改编阶段重新施测 |

> 判定基于**报告 + 专家审阅**，脚本只给统计证据。任何「通过」结论都需要指导教师签字，不能由脚本自动宣告。

```bash
# SQLite 部署：直接读库（只读打开，不写库）

# 任意后端 / 外部复核：读匿名导出 JSON

--strict                   # 任一项未达标时退出码 2（便于将来接 CI）
```

- 报告内容：样本量、每维 α + 判定 + 低 CITC 题号、六维相关矩阵、重测 r、百分位候选（带样本量档位）、判定汇总、局限与 O\*NET 授权声明。

## 8. 风险与限制

- **代表性**：单校/单班样本只代表同类人群，不能外推全国；跨班复验可缓解。
- **自评偏差**：兴趣自评受社会赞许与近期经历影响；重测间隔过短会高估稳定性，过长会低估。
- **样本量**：n < 60 时 α 与相关的置信区间宽，脚本会显式标注「样本不足」。
- **单一方法**：只有自评问卷时无法排除共同方法偏差；校标效度与专家审阅是关键补充。
- **题目改动**：任何题面改动都要升版本并重跑验证，不能用上一轮的结论覆盖新一轮。
- **用途边界**：结果仅用于职业兴趣探索与教学参考，**不作为心理诊断或选拔依据**（与现有免责声明一致）。

### A.1 `--export` JSON 格式（匿名）

```json
{
  "assessment": {
    "code": "riasec",
    "name": "霍兰德职业兴趣测评（Mini-IP 精简版）",
    "scaleVersion": "Mini-IP-CN 1.0",

      "studentKey": "p01",
      "completedAt": "2026-10-19 10:00:00",
```

- `studentKey`：**匿名且稳定**的键（同一学生多次完成用同一个键；可用编号或哈希，禁止直接用学号）。

### A.2 MySQL 导出 SQL（导出后自行把 `user_id` 换成匿名键）

```sql
SELECT r.user_id,
       r.answers_json,
       r.scores_json,
       r.completed_at
  FROM assessment_results r
  JOIN assessments a ON a.id = r.assessment_id
 WHERE a.code = 'riasec' AND r.status = 'completed'
 ORDER BY r.user_id, r.completed_at, r.id;
```

```sql

  FROM assessments a WHERE a.code = 'riasec';

SELECT q.question_index, q.dimension, q.reverse_scored
  FROM assessment_questions q
  JOIN assessments a ON a.id = q.assessment_id
```

## 附录 C：术语

- **α（Cronbach's alpha）**：内部一致性系数，衡量同一维度内题目是否测同一个东西；受题目数与样本同质性影响。
- **CITC**：校正题总相关，单题与该维度其余题之和的相关，用于找「拖后腿」的题。
- **重测信度**：同一批人隔一段时间做两次的一致性，反映稳定性。
- **校标效度**：与另一个公认测量（英文原版）的相关，反映「测的是不是同一个构念」。
- **常模**：把原始分映射到人群位置的参照系（百分位 / T 分 / 等级），需要足够大且有代表性的样本。
- **EFA / CFA**：探索性 / 验证性因子分析，检验「30 题是不是真的落在六个因子上」。
